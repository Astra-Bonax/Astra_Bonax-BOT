# Astra_Bonax-BOT
Discord Moderation BOT (Example)

Astra_Bonax è un Bot Discord progettato per moderazione, gestione ticket e logging degli eventi principali del server.  
Questo progetto rappresenta una **bozza funzionale** pensata per mostrare competenze tecniche, struttura del codice e organizzazione professionale all’interno di un portfolio.

---

## 🚀 Funzionalità Principali

- **👋 Messaggi di Benvenuto e Addio**  
  Notifica automatica quando un utente entra o esce dal server.

- **⚠️ Sistema WARN**  
  Registra avvisi moderativi in un file JSON per mantenere la cronologia anche dopo riavvii del bot.

- **⛔ Sistema BAN**  
  Registra i ban in un file JSON.  
  
- **🎫 Sistema Ticket**  
  Creazione di canali dedicati per assistenza o richieste degli utenti.

- **📝 Sistema di Log**  
  Registra eventi importanti in un canale dedicato (JOIN, LEAVE, WARN, BAN, TICKET).
